# Security policy

inBetween handles payments and identity documents, so we take reports seriously.

## Reporting a vulnerability

Please **don't open a public issue**. Report it privately through [GitHub security advisories](https://github.com/Ziad-irl/inbetween/security/advisories/new). Include steps to reproduce and the impact you expect.

We aim to acknowledge reports within 3 business days and to keep you updated until a fix ships.

## Scope

The code in this repository and any inBetween environment. Social engineering, physical attacks and denial-of-service tests are out of scope.
